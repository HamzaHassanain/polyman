# AGENTS.md

This problem directory uses [`CLAUDE.md`](./CLAUDE.md) as the single agent-orientation document. It explains the problem-package layout (solutions, generators, validator, checker, statements, tests), the `Config.json` schema, the solution-tag verdict system, the polyman command reference, and the most common workflows (add a solution, add a generator, sync to Polygon, etc.).

**All AI agents — Claude Code, Cursor, Aider, Codex, Continue, etc. — should read [`CLAUDE.md`](./CLAUDE.md) for orientation and [`AUTHORING.md`](./AUTHORING.md) for the non-negotiable authoring rules (three modes, per-artifact patterns, C++ performance standards) before changing anything in this directory.**

The content is agent-agnostic; the filenames are historical. If your tool prefers `AGENTS.md`, this file points you to the same content.
